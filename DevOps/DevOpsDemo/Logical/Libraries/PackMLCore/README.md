Core library for PackML state managing and heap utilization of Equipment Modules 

## NOTE:
This is the core library (PackMLCore) and cannot be used on its own

This library is used by the IEC interface library [BrdkPackML](https://github.com/BRDK-Public/BrdkPackML)

It is implemented as a git submodule in the BrdkPackML repository
